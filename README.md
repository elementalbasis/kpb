# Kustendja Polyglot Bible

A multilingual biblical corpus of the Bible in Greek, Latin, Slavonic, and
English. Intended to serve as references to translate the Bible into Danetian.

* The **Greek** translation is composed of
[Rahlfs' Septuagint](https://github.com/deuterotheodore/LXX) and the
[SBL Greek New Testament](https://github.com/FaithLife/SBLGNT).
* The **Latin** translation is taken from the
[Clementine Vulgate](https://github.com/LukeSmithxyz/vul).
* The **Slavonic** translation is taken from the
[Elizabeth Bible](https://github.com/scrollmapper/bible_databases/blob/master/sources/cu/CSlElizabeth/CSlElizabeth.json).
* The **English** translation is composed of
[Brenton's Septuagint](https://ebible.org/find/details.php?id=eng-Brenton)
for the Old Testament and
[Douay-Rheims](https://github.com/eastrocky/dra) for the New Testament.



## Book witnesses

There are some books in the Greek Septuagint that have more than one variant.
The Danetian translation will be based on the following choices, because they
are the most broadly compatible between the four languages:
* Joshua B (JoB)
* Judges B (JuB)
* Tobit B (TbB)
* Daniel Theodotion (DaQ)
